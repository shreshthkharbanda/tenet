# Configuration

The Router (`litellm.Router`, defined in `litellm/router.py`, with helpers in `litellm/router_utils/`) reads
its configuration from six sources. It does not open or parse a configuration file itself.

1. Keyword arguments to `Router(...)`. The proxy fills these from the YAML `router_settings` block ([CFG-089]).
2. Process environment variables. Most are read once when `litellm.constants` is imported; a few are read
   every time a deployment is built or a request is routed.
3. Mutable module-level globals on the `litellm` package (`litellm.num_retries`, `litellm.fallbacks`, ...),
   used as fallbacks when a constructor argument is not given.
4. Per-deployment keys inside each `model_list` entry (`litellm_params`, `model_info`).
5. Per-request keyword arguments passed to `acompletion`, `aembedding` and the other entry points.
6. Runtime changes through `Router.update_settings(**kwargs)`.

This file is an index. Each row names the module claims that specify the setting; the module specs own the
behavior. Claims written here state only what no module owns: values defined outside the Router (in
`litellm/constants.py`, `litellm/__init__.py`, the type models and the proxy), how sources combine across
modules, and settings that have no effect anywhere. All durations are in seconds unless a row says otherwise.
"Read by" names the module that reads the setting and when.
